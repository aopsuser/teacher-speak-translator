Project

Teacher-Speak Translator — "From teacher to human."

Problem

Students lose points not because they don't know the material, but because they don't understand what the assignment asks for. Phrases like "discuss more fully" or "be creative" are everywhere, and many students are too shy to ask. Teachers face the same problem from the other side: they rarely find out an assignment was unclear until the work comes back.

What it does

  • Student mode: paste a vague assignment. A rule-based Fog Meter highlights vague phrases instantly (1–10). Claude then explains what the teacher most likely expects, what a strong answer contains, a self-check list, and a polite question to ask the teacher. It never writes the assignment for the student.
  • Teacher mode: paste your assignment before handing it out. Get a clarity score, the problem phrases, and a clearer rewrite.

Built with

HTML, CSS and vanilla JavaScript in a single file. Fog Meter: hand-written regex dictionary (English and Russian), no AI. Explanations: Claude through the Artifact sample capability. Hosting: Claude Artifacts. No datasets, no external APIs, no data stored.

AI-use disclosure

We used Claude to brainstorm and pick the idea, to write the first version of the code and the prompts, and to draft this text. The product itself uses Claude at runtime for the translation features. The vague-phrase dictionary and scoring rule are plain code we can explain line by line. The prompt tells the model not to do the student's homework.
